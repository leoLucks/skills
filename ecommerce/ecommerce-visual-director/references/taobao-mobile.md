# 淘宝/天猫无线端页面模块

1. 先区分店铺首页、商品详情页、活动页、PC 专属与无线端专属；需求表原文优先。
2. 列需求矩阵：ID、模块、目标、文案原文、产品图来源、显示平台、顺序、尺寸、按钮/链接、验收条件。
3. 以手机单列逻辑排版：不同模块一屏一重点，注意实际手机缩放后的文字大小、留白、分类卡片与点击热区。不能把 PC 设计简单缩小。
4. 如平台尺寸未知，可先用 750px 宽作为 **提案画布**，不是平台官方合规证明。导出尺寸须按用户指定或最新官方要求核实。
5. 每个独立模块独立文件；可另外生成长图预览，但预览不是独立交付物替代。使用 `01-hero.png`、`02-category.png` 等有序命名并生成 manifest。
6. 适配工业标签和 RFID/NFC 类产品时，类目和 SKU 图逐一对照。防止标签、卡片、硬标签、特殊工业标签混淆；不编造频率、参数、性能。
7. 多模块统一 Style Lock，但构图要变化；中文文案逐字对照，图中不能凭空加“销量第一”“官方认证”等。
8. QA 验证模块数量、顺序、文字、产品实物及文件尺寸，发现失败必须局部修复并复检。

输出：需求矩阵、手机端页面结构、逐屏制作卡、交付清单、质检摘要。
