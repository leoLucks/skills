# 参考图分析模块

适用：参考图、竞品页面、现有成品、商品实拍照。

1. 给每张图设 ID 和类别：`产品事实来源 / 风格参考 / 需求截图 / 竞品案例 / 待检成品`。
2. 仅描述可观察事实：构图、留白、主体占比、光线、视角、文字层级、纹理、颜色族；对字体/颜色/尺寸的猜测标注估计。
3. 输出风格指纹：商业语气、摄影真实度、明暗/冷暖、结构、信息密度、可复用规则。
4. 建立 Product Identity Lock：产品形状、颜色、材质、Logo/标签、配件、数量、尺寸/接口（仅限有证据的属性）。禁止增删改产品实体。
5. 参考取舍：`必须保留 / 可借鉴 / 应重做 / 禁止照搬`。竞品 Logo、品牌识别和受保护创意不得复制。
6. 把参考图转化为生产指令，不只是“照着做”。和需求冲突时按主 SKILL 优先级处理。

输出：图像清单、风格指纹、产品保真清单、取舍表、风险、设计简报。
